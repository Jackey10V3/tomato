# 免费云端部署指南（Render + MongoDB Atlas）

> 目标：让手机在**任何网络**（流量/外面 WiFi）都能连上云端，注册/登录后自动同步。
> 零成本方案：后端部署到 Render 免费层 + 数据库用 MongoDB Atlas 免费集群（M0，512MB，够用很久）。

## 0. 前置

- 一个 GitHub 账号（Render 从 GitHub 拉代码）
- 一个 MongoDB Atlas 账号（邮箱注册即可）
- 约 30 分钟

## 1. 把代码推上 GitHub

```bash
cd D:\fastapi\tomato
git remote add origin https://github.com/<你的用户名>/tomato.git
git push -u origin master
```

> 仓库里已包含部署所需的一切：`render.yaml`（Render 蓝图）、`server/`（后端）。

## 2. MongoDB Atlas 建免费库

1. 注册/登录 https://www.mongodb.com/cloud/atlas → 创建 **M0 Free** 集群（区域选 Singapore/AWS 最近）；
2. **Database Access** → Add User：账号密码自定（角色 Atlas admin 即可），记下来；
3. **Network Access** → Add IP → 填 `0.0.0.0/0`（允许所有来源，配合强密码使用）；
4. **Connect → Drivers** → 复制连接串，形如：
   `mongodb+srv://<user>:<pass>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority`
   在 `.net/` 后面**补上数据库名** `tomato`：
   `mongodb+srv://<user>:<pass>@cluster0.xxxxx.mongodb.net/tomato?retryWrites=true&w=majority`

## 3. Render 部署后端

1. 登录 https://dashboard.render.com → **New → Blueprint** → 选你刚推的仓库；
2. Render 自动读取 `render.yaml`，部署时**提示填 `MONGODB_URI`** → 粘贴上一步的连接串；
   （`JWT_SECRET` 会自动生成强随机值，不用管）
3. 点 Deploy，等 2~3 分钟；部署成功后会得到地址，形如：
   `https://tomato-server-xxxx.onrender.com`
4. 浏览器打开 `https://tomato-server-xxxx.onrender.com/health`，看到 `{"code":0,...}` 即成功。

## 4. App 指向云端

改项目根目录 `.env`：

```
VITE_API_BASE=https://tomato-server-xxxx.onrender.com/api/v1
```

然后重新构建运行（H5 / 鸿蒙都要重新构建，API 地址是编译时打进包里的）。
App 里注册/登录后，登录页顶部会显示「**云端已连接**」。

## 5. 注意事项（免费层须知）

- **休眠**：Render 免费层 15 分钟无流量会休眠，下一次请求要**冷启动约 30~60 秒**。
  App 请求超时会提示失败，**再点一次就好**。也可以用免费的 cron（如 cron-job.org）
  每 10 分钟 ping 一次 `/health` 保活。
- **离线数据不补传**：断网期间的专注记录只存在手机本地，上线后**不会自动补传**
  （代码里是 `TODO(M3) outbox 队列`）。部署云端后产生的新记录会实时上云。
- **限流**：注册/登录接口加了限流（同 IP 5 分钟 20 次），正常使用碰不到。
- **安全**：JWT_SECRET 由 Render 自动生成；Atlas 用强密码 + 只开必要权限。
  想更稳可以后续给 Render 绑自定义域名开 HTTPS（Render 默认域名已是 HTTPS）。

## 6. 回退

任何时候删掉 `.env` 里的 `VITE_API_BASE` 或改回 `http://127.0.0.1:3000/api/v1`
再重新构建，App 就回到"本地模式"（本地登录/本地数据，完全离线可用）。

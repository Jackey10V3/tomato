# 🍅 番茄Todo · 使用说明（当前版本）

> 根目录 `README.md` 因被本机某进程占用无法覆盖，故新版说明放在此处。

App 形态：**待办 → 专注 → 统计 → 成就** 的本地优先番茄钟（Uni-app / Vue3 + TS）。

## 功能
- **待办**：右上角 ＋ 弹卡片添加（名称 / 倒计时 30·60·自定义分钟 或 正向计时）；多彩卡片显示时长与「今日已专注 N 次」；点击进入专注页，**长按编辑/删除**；顶部**考研倒计时**卡（天/时/分实时，点按或长按改名称与时间）；今日概览条；等级徽章入口；首次引导。
- **专注（二级页）**：整屏沉浸、顶部励志语、细环大时间（倒计显剩余 / 正计显已专注）；底部 暂停·结束·放弃（**自有确认卡片**）；圆环呼吸动效、完成/升级撒花；严格模式与学霸模式（离席警告超限作废）。
- **统计数据**：累计专注（次数/总分钟/日均）、当日专注、**日/周/月/年扇形分布**（图例含名称与时长、可分享文本报告）、本月时段分布；「查看专注记录」→ 记录页（筛选、长按删除、导出文本）。
- **成就**：27 枚徽章（时长 1h→300h、番茄 1→365、连续 3→100 天、单日/单次强度、早起夜猫等）+ 等级经验与 10 段称号，成就墙带进度条与四档分色。
- **我的**：本地登录/注册（离线、加盐哈希）、头像与昵称、等级/天数药丸、主题快捷切换、外观与音效、计时设置、强力专注（白名单）、**数据管理（导出/恢复备份）**。
- **外观与音效**：6 主题 + 深色模式（含底栏配色）、5 款背景海报、4 类提示音可试听 + 一键测试、音量滑杆、7 音源白噪音多轨混音（WebAudio 合成，无需素材）。

## 运行
```bash
npm install
npm run dev:h5      # http://localhost:5173（F12 手机视图）
npm run build:h5
npm run type-check
```
安卓/鸿蒙 App 用 HBuilderX 打开项目运行，原生能力接入点见 `src/platform/*`。

## 颜色与数据约定
- 全站颜色只取自主题 token（`src/utils/theme.ts`：`--p-primary/-light/-deep/-bg/-card/-text/-sub/-grad/-soft/-border/-shadow`），图表色板与卡片渐变均由主题主色派生 → 换主题或深色模式全站一致。
- 数据在 `tomato:*` 存储键下，带 schema 版本（`utils/migrate.ts`），升级只补齐不覆盖；建议定期在「我的-数据管理」导出备份。
